## Slave - Miners

Slave - Miner is new profession for villagers. This villager has only one task - to mine naquadah and 
take it to the nearest available inventory - e.g. chests. This profession can be obtained by any type 
of villager if villager accept a cauldron with melted raw naquadah as work station.
