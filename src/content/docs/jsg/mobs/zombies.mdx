If priest villager is killed by zombie or zombie villager, same rules apply to turning him into a zombie 
villager as for a standard villager. So on easy difficulty the chance is 0%, on normal difficulty it is 50%, 
on hard difficulty it is 100%.

Zombie Priest Villager can be healed just like regular villager. Again, the same procedure and rules 
apply for this healing. Zombie Villager must be under Weakness effect before the healing can be initiated 
with Golden Apple. If healing is successful, Zombie Villager will transform back into Priest type Villager
