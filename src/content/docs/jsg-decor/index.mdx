JSG: Decoration is an official addon for Just Stargate Mod that adds high-resolution decorative content, primarily inspired
by the Stargate Atlantis TV series. It expands the base game with new blocks, trees, walls, glass blocks, and much more.

The addon requires JSG: Core and the base JSG mod to be installed.
