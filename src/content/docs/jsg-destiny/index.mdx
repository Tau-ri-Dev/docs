JSG: Destiny is an official addon for Just Stargate Mod that adds content inspired by Stargate Universe TV series.
It expands the Just Stargate Mod base game with new blocks, items and machines such as destiny floor chevron, gate bearing
and a lot more.

The addon requires JSG: Core and the base JSG mod to be installed.
